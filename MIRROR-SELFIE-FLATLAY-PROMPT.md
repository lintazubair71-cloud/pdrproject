# Default image style — Mirror-Selfie + Flat-lay

**This is the standard image for every article on The Wow Style.** One vertical
image in two parts: on the **left** the model takes a mirror selfie with the phone
held over the face; on the **right** the same outfit as a flat-lay. Because the
face is hidden by the phone, **you do not need a reference photo and the model can
never drift.** Works for men and women.

> The old face-locked portrait files (`FEMALE-MODEL-PROMPT.md`, `MALE-MODEL-PROMPT.md`)
> are only for the rare image where a face IS shown (e.g. an author portrait). For
> everything else, use this style.

## How to use (ChatGPT)

1. One chat is fine. **No reference photo needed** — the face is hidden.
2. Copy a template below, change the bracketed lines, send, download.
3. Save to the filename in the article's image pack; paste the alt text in WordPress.
4. The `thewowstyle.co.uk` watermark is added **after**, by the WordPress plugin — not by the AI.

## What changes per image

- **OUTFIT** — top, bottoms, shoes, accessory. Always names the shoes.
- **POSE & PHONE** — a different stance and phone position each image (there is no
  face angle to vary; the face is hidden).
- **BACKGROUND** — a different plain wall + surface colour each image.

Everything else stays word-for-word so the set holds together.

## POSE & PHONE — change every image

Never the same one twice in a row.

| # | Pose & phone |
|---|---|
| 01 | Phone held high in one hand, the other hand in a pocket, weight on one leg |
| 02 | Phone to one side at chest height, body turned slightly to the mirror |
| 03 | Phone centred with both hands, standing square |
| 04 | Phone high, free hand resting at the side, mid-stance |
| 05 | Phone up, slight lean, ankles close |
| 06 | Phone at eye height, one knee soft, relaxed shoulders |

## BACKGROUND — a different colour every image

soft warm-grey · muted sage green · pale clay (muted terracotta) · dusty muted blue ·
warm oatmeal beige · soft greige · muted olive · pale blush-stone

## Rules that always apply

- **Face hidden by the phone** — never a visible face (this is what stops the model drifting).
- **Shoes shown worn AND in the flat-lay.**
- **Vary the accessory every image** — a necklace, a watch, sunglasses, a belt, earrings, a cap, a small bag or rings, or none. Never the same accessory in every image.
- **Vertical 2:3** (1000×1500) for the look. The **featured image is separate: horizontal 1200×700, WebP**.
- The **flat-lay must match the worn outfit exactly** — same pieces, same colours.
- **Watermark `thewowstyle.co.uk`** added after generation, bottom-right, ~55% opacity (WordPress plugin). The prompt keeps "no text/watermark".
- Keep a **consistent one-line body + hair description** through a guide so the person reads as the same model.
- Every image in a pack states its **filename, alt text and the section** it goes in.
