## Three rules before you start (from CLAUDE.md)

1. **Attach the model's reference photo to *every* message**, not just the first — text alone won't hold the face.
2. **Same wall and light for the whole page.** For this pillar both models use the **warm-grey studio wall + pale oak floor** with window light from camera-left. *(This is the one change from the male file, whose default is a panelled room — we override it here so the man and woman match on the same page.)*
3. **Shoes visible in every shot**, and **never reuse one photo in two slots** — all 8 below are distinct.

## Quick checklist as you generate

- [ ] Reference photo attached on **every** message (women's chat uses her photo, men's chat uses his).
- [ ] Only the **OUTFIT / POSE / DETAIL** lines change within each model's set — everything else word-for-word.
- [ ] Every outfit names the **shoes**, and the shoes are visible in the frame.
- [ ] Same **warm-grey wall + left daylight** across all 8 (man overridden to match).
- [ ] Each image saved to the **exact filename** above (slug-matched, so the site picks it up).
- [ ] No pose repeats back-to-back within one model's set (Woman: 01 → 05 → 03; Man: 01 → 04).
